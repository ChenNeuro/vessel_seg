# archive

这个目录用于存放已经退出工程主线、但仍需保留追溯性的历史文件。

归档原则：

1. 主线代码不放这里  
   当前主线代码只放在 `vessel_seg/`、`vessel_seg/pipeline/` 和 `scripts/pipeline/`。

2. 只归档以下内容  
   - 根目录历史杂项
   - 一次性演示脚本
   - 汇报材料生成脚本
   - 旧版示例图片、临时 notebook、无关资产

3. 归档不等于删除  
   被移入 `archive/` 的文件仍然保留，方便后续追溯、复用或人工检查。

4. 归档内容默认不再维护  
   除非明确需要恢复，否则不要继续在 `archive/` 中开发新逻辑。

当前结构说明：

- `legacy_root/`：原先放在仓库根目录、但不属于工程主线的历史文件
- `scripts_legacy/`：一次性脚本、汇报脚本、特定病例演示脚本
- `infra/`：与主工程无关的基础设施或外部运行目录
